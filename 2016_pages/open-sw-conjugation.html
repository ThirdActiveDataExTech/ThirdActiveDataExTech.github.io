프로젝트 목표

써드파티 데이터의 활용성 증대를 위해 지능적인 데이터 관계 분석 및 데이터 자동 연결 확장을 수행하는 액티브 메타데이터 기반 능동형 데이터 확장 기술 개발

기본 아키텍처

시스템 개요도

기능적 특징

1. 액티브 메타데이터 구조 설계 및 처리 기술

데이터의 특성 및 관계를 포함하는 액티브 메타데이터 구조를 설계하고 액티브 메타데이터 처리를 통해 데이터 카탈로그를 구성한다.
데이터 변화를 반영해 갱신하는 액티브 메타데이터 구성 기술을 제공한다.

2. 액티브 메타데이터 기반 데이터 간 관계 생성 기술

액티브 메타데이터를 기반으로 데이터의 특징을 추출하고 분석한다.
인공지능을 기반으로 데이터 간 상호 연관성을 분석한다.

3. 지능형 데이터 자동 탐색 및 패키징 기술

액티브 메타데이터를 기반으로 데이터 자동 탐색 기술을 제공한다.
데이터 활용을 목적을 기반으로 한 데이터 자동 탐색 기술을 제공한다.
탐색 데이터의 확장 통합 구성을 위한 능동형 데이터 확장 기술을 제공한다.
써드파티 데이터의 동적 변화 반영을 위해 데이터 파이프라인을 자동 구성하는 기술을 제공한다.
데이터 제공의 신뢰성을 보장하기 위해 능동형 데이터 패키징 기술을 제공한다.

4. 써드파티 데이터 활용 환경 제공 통합 플랫폼 기술

다종 써드파티 데이터를 연계하는 액티브 메타데이터 생성 기술을 제공한다.
액티브 메타데이터 기반 데이터 관계 분석 및 자동 탐색 도구를 제공한다.
데이터의 특징 및 관계 분석 결과를 보여주는 데이터 시각화 기술을 제공한다.
데이터의 적합성을 검증하고 공유하는 기술을 제공한다.
