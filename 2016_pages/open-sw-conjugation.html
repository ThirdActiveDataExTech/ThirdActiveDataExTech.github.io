수요분석

주요 수요처 예상

- 새로운 데이터의 갱신 주기가 빠른 대량의 데이터 보유 공공기관
- 다종 정형 반정형 비정형 공개 데이터를 활용하는 공공기관
- 데이터 관리와 분석을 통해 디지털 전환을 추진하려는 기업
- 분산 저장된 데이터를 활용해야 하는 데이터 분석 활용기업

수요 분야와 시나리오 예상

수요분야 수요별 예시
의료 질환 및 진단에 대한 임상, 영상 등의 정보 변화를 반영한 액티브 메타데이터를 활용하여 환자의 치료 방법을 검색 및 추천하는 서비스
교통 시간대별 교통량 정보, 교통사고 정보, 차량 이동량 정보와 같은 변화를 반영한 액티브 메타데이터 기반 인프라 정책 해결 서비스
데이터 환경/기후, 에너지, 교통 등 다종 데이터의 특성 및 연결 정보를 포함하는 액티브 메타데이터를 사용하여 사용자의 데이터 활용 목적에 맞는 통합 데이터를 구성하고 제공하는 서비스
인공지능 인공지능 학습을 위한 멀티 모달리티 데이터셋 구성/제공 서비스 및 지식 그래프 기반 데이터 관계 분석 기술을 활용하는 인공지능 의사결정 서비스
마케팅 고객 트랜잭션, 구매 패턴, 인구 통계등 다종 소스로부터 수집되는 고객 데이터를 액티브 메타데이터 기반으로 통합/분석하여 마케팅의 효율성을 개선하는 서비스

실증 사례

수요 분야 중 마케팅과 의료 분야를 대상으로 수요기관 연계 실증을 진행하고 있습니다.
두 사례 모두 기관 보유 데이터(1st)와 외부 써드파티 데이터(3rd)를 액티브 메타데이터 기반으로 연결해, 현장 사용자의 의사결정에 활용합니다.
구분 방송 광고 추천 API 맞춤형 건강정보 제공 서비스
분야 / 수요기관 마케팅 / SBSi 의료 / 연세의료원
사용자 광고 집행 담당자 의료진
입력 → 출력 광고 키워드 → 타겟 성별·연령 비중 환자 암종 → 암종별 건강정보 후보
진행 현황 API 개발 목업 화면 개발 완료, 실증 진행 중

사례 1. 방송 광고 추천 API

시청 로그만으로는 변화하는 소비 트렌드를 반영하기 어렵습니다. 쇼핑 트렌드 데이터를 결합해 광고 키워드별 타겟 성별·연령을 API로 제공합니다.
구분 데이터
1st 시청 로그, 광고주 브랜드(업종 키워드), 방송 주요 장면 키워드
3rd 쇼핑 카테고리별 성별·연령 트렌드 (주간 자동 수집)
처리 흐름 : 수집·변환 → 회차별 시청 비율 집계 → 매핑표로 키워드·카테고리 연결 후 가중 결합 → API 제공

액티브 메타데이터 기술 적용
- 써드파티 쇼핑 데이터를 자체 수집기로 주간 갱신
- 매핑표로 광고 품목과 쇼핑 카테고리를 의미적으로 연결

사례 2. 맞춤형 건강정보 제공 서비스

의료진이 환자 암종에 맞는 건강정보를 매번 찾기 어려운 문제를 해결합니다. 영상·웹 건강정보를 수집해 암종별로 연결하고, 화면에서 선택해 제공할 수 있도록 합니다.
구분 데이터
1st 암종별 건강정보 큐레이션 출처, 환자 암종 정보
3rd 의료기관 채널 영상 메타정보 (주간 자동 수집), 웹 건강정보
처리 흐름 : 원천 데이터 수집 → 암종 키워드 기반 매핑 → 조회·상세·편집·출력·등록 화면 제공 (실증 범위: 5대암)

액티브 메타데이터 기술 적용
- 의료기관 채널 영상 메타정보를 자체 수집기로 주간 갱신
- 환자 암종(1st)과 건강정보(3rd)를 암종 키워드로 연결
