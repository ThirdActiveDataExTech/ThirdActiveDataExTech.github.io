과제개요

다양한 목적과 규격으로 생성되는 데이터들에 대해 데이터 간 관계 분석, 통합 검색/탐색, 그리고 동적으로 변화하는 다종 데이터의 메타정보 특성을 반영한 액티브 메타데이터 기반 기술을 통해, 산업 및 도메인 분야의 특성과 목적에 맞게 확장하여 데이터 패키징 등 데이터 자산을 더욱 효율적으로 활용할 수 있게 하는 지능형 데이터 통합 자동화 환경 제공 기술을 제공합니다.

빅데이터 기반 데이터 확장 기술 문제점

기존 데이터 활용은 데이터 연계·통합이 수작업 중심으로 운영되어 시간과 비용 부담이 크며, 비정형 데이터의 메타정보 부족과 신규·기존 데이터 간 관계 파악의 어려움으로 인해 데이터의 효율적 활용과 연계·통합에 한계가 존재합니다.

액티브 메타데이터 기반 능동형 데이터 확장 기술의 필요성

데이터 활용을 위한 구축 환경 변화와 데이터 규모 증가에 따른 복잡성 해결, 실시간 자동화 데이터 처리에 대한 수요가 급격히 증가하고 있으며, 다양한 데이터를 효과적으로 관리 및 활용하기 위해서는 능동적인 데이터 처리 기술이 필요합니다.

과제목표

써드파티 데이터의 활용성 증대를 위해 지능적인 데이터 관계 분석과 데이터 자동 연결·확장 기능을 수행하는 액티브 메타데이터 기반 능동형 데이터 확장 기술을 위한 데이터 활용 통합 플랫폼 기술을 개발합니다.

연구개발 구성

자동 탐색 및 패키징 검색, 목적에 맞는 탐색, 확장·통합, 파이프라인 자동 구성, 패키징 모비젠
