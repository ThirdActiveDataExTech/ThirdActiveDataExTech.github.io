써드파티 데이터(Third Party Data)란?

데이터 생성 주체와 직접적인 관계가 없는 법인 혹은 데이터 브로커로부터 수집된, 타 기업으로의 판매 또는 세분화 타겟 마케팅 활동이 가능한 대규모 데이터 세트

액티브 메타데이터

데이터의 데이터. 데이터 및 분석 사용 사례에 대한 지속적인 분석을 지원하기 위해 필요하며, 데이터 관리와 데이터 분석 프로세스에서 실제 데이터와 함께 동적으로 사용됩니다. 조직이 데이터 자산을 이해하도록 돕는 역할을 합니다.

능동형 데이터 확장 기술

액티브 메타데이터 기반 기술을 통해 상시 동작하며 지능적으로 데이터를 생성하고 관리하여 사용자에게 메타데이터 저장, 관리, 검색, 탐색, AI 기반 데이터 관계 분석, 데이터동적 변화 분석 및 반영 등을 제공할 수 있는 기술.
최신 데이터 통계 정보를 지속적으로 수집 및 관리하며 데이터 간 관계를 지능적으로 인지하여 지속적인 데이터 연결 관계를 자동 생성함.

과제연구내용

1. 액티브 메타데이터 구조 설계 및 처리 기술

가. 데이터의 특성 및 관계를 포함하는 액티브 메타데이터 구조 설계
나. 데이터 카탈로그 구성을 위한 액티브 메타데이터 처리 기술 개발
다. 데이터 변화를 반영한 데이터 갱신 기능 지원 액티브 메타데이터 구성 기술 개발

2. 액티브 메타데이터 기반 데이터 간 관계 생성 기술

가. 액티브 메타데이터 기반 데이터 특징 추출 및 분석 기술 개발
나. 인공지능 기반 데이터 간 상호 연관성 분석 기술 개발
다. 데이터 패턴 모델링 및 네트워크 분석을 통한 데이터 간 관계 생성 기술 개발

3. 지능형 데이터 자동 탐색 및 패키징 기술

가. 액티브 메타데이터 기반 데이터 검색 기술 개발
나. 데이터 활용 목적 기반 데이터 자동 탐색 기술 개발
다. 탐색 데이터의 확장 통합 구성을 위한 능동형 데이터 확장 기술 개발
라. 써드파티 데이터의 동적 변화 반영을 위한 데이터 파이프라인 자동 구성 기술 개발
마. 데이터 제공의 신뢰성을 보장하는 능동형 데이터 패키징 기술 개발

4. 써드파티 데이터 활용 환경 제공 통합 플랫폼 기술

가. 다종 써드파티 데이터 연계형 액티브 메타데이터 생성 기술 개발
나. 액티브 메타데이터 기반 데이터 관계 분석 및 자동 탐색 도구 개발
다. 데이터의 특징 및 관계 분석 결과에 대한 데이터 시각화 기술 개발
라. 데이터의 적합성 검증 및 공유 기술 개발

5. 실증 시스템 구축 및 시범서비스 적용

가. 능동형 데이터 확장 기술에 대한 수요 또는 수혜 기업 기관  연계형 실증 시스템 구축
나. 이종 도메인 데이터 기반 능동형 데이터 확장 기술에 대한 시범서비스 적용

1) 데이터 활용성 증대

가) 동적으로 변화하는 데이터의 특성을 반영하여 통합적인 데이터 관리 체계를 구축하고 다종 데이터의 특성을 반영하여 복합분석이 가능한 기술 토대 마련 가능
나) 액티브 메타데이터 구성 및 분석을 통해 데이터의 가치와 활용성 향상이 가능하 고 능동형 데이터 패키징 및 데이터 파이프라인 자동 구성을 통해 해당 도메인 지식이 부족한 비전문가도 데이터를 효율적으로 활용할 수 있는 환경 제공 가능

2) 자동화된 통합

가) 액티브 메타데이터 기반 데이터 연결 및 관리를 통해 관련 데이터 검색 및 수집에서 전달 및 소비에 필요한 시간과 노력을 획기적으로 단축 가능
나) 연관 데이터 활용 검색 수집 전달 소비 등 을 위해 소요되는 시간과 노력을 획기적으로 단축 가능
다) 빅데이터 플랫폼 사용자들이 필요한 데이터를 쉽게 탐색하고 제공받을 수 있는 환경 확보 가능
라) 비 전문가도 데이터를 쉽게 확보하고 활용할 수 있는 생태계를 조성하여 4차산업혁명에 참여하는 데이터 과학자 저변확대 가능
